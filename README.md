# windows-ime-bench

给 Windows 拼音输入法打分：模拟真人打字（连续全拼 + 空格上屏），看它打出来的
字和你想打的字一不一样。整句、两个字到四个字的高频词、联网和断网四种成绩都测。

结论速记：

- **微信在线整句第一（70.83%，两轮逐位一致），但清缓存断网后 35.83%（−35）**：
  整句优势依赖联网数据；纯本地榜 QQ 62.50% 领跑（QQ/千问/墨奇/手心/微软/水杉
  在线离线零变化）。
- **豆包 65.00% 是本地能力、离线第一（深清验证后定案）**：离线 65.00 与在线使用态
  逐句一致（78/78）；再深清 `engine_storage.leveldb`（上轮遗漏的学习载体）后**仍
  78/78 一致**——不靠云、不靠任何学习数据。10-25 干净 43~45 与如今 65 之差主因是
  产品本地能力升级（版本混杂），非用户学习。离线本地榜：**豆包 65.00 > QQ 64.17 >
  千问 60.83 > 中文 59.17 > 微信 35.83**。详见 final_report「二·补三/补四」。
- **QQ 拼音 64.17%（在线=离线，两轮逐句完全一致 77/77）**：与 10-26 干净在线 62.50
  差 1.7 点（CI 内），是真实稳定水平而非清理残留。附注：QQ 词库删后会被进程内存
  副本还原（脚本能检测并告警），要绝对干净需卸载重装或重启。
- **微信是唯一云依赖（离线复测二轮复现）**：离线 35.83 vs 在线 70.83（−35），
  与 10-26 干净离线轮逐位一致；其余三家离线≈在线，纯本地。
- **拼音直落=打字太快，30ms 键隔可消除（11-17 键隔实验）**：豆包词级 ASCII
  直落 12ms=10 个 → 30ms=0（96.00→99.33），句测三家分数不动。有此问题的仅
  豆包（间歇）与谷歌（持续）；微信/千问/墨奇 12ms 即 0 直落。属部分 IME 对高速
  合成按键的响应能力差异，非词库问题。详见 final_report「二·补二、键隔实验」。
- **11-17 复测轮**：微软商店新发布的「中文输入法」（实为 Bing 键盘）与墨奇
  v2.0.7 同分（整句 59.17%、词 99.33%），但错误结构零重叠——墨奇错在专业语境
  同音词选择（候补→后部、凉意→两翼），中文输在长句尾部截断+生僻组合不出词
  （「泥泞」打出「您ing」）。首装首跑口径，稳态待复测。
- **谷歌 9.17（11-14）/30.83（10-26）定性修订**：11-14 曾判「词典污染真实劣化」，
  11-17 同一词典未清、仅手动切换输入法即回到 42.50/93.78——主因是 TSF 激活/
  切换故障（上屏串混拼音直落为按键未进转换的特征），词典污染即使有也非主因。
  谷歌对程序化合成按键吃键不全（本轮残留 4 句/8 词 ASCII），真人手打预计略高。
- **墨奇 v2.0.7 整句 55.00→59.17**（与 11-14 使用态轮同口径对比）：含词库更新
  （地名/车站/机场/企业名补丁）与学习效应两部分，不可全归因产品；11-14 时
  −2.5 的波动在本轮消失。
- **联网依赖实锤两家：微信 −35、百度 −17.5**；搜狗新装在线离线逐位相同（双
  55%）、豆包断网不降——两家云增益均为 0，重置脚本误清搜狗共享词库时会假低
  到 35%（脚本已修）。
- **素言/清风词级满分**（整句偏弱）。
- 华宇 V6.9（2017 停更）纯本地无云，整句 53.33% 仍在一梯队下沿，**全场最轻**
  （包 17MB/目录 14MB/零常驻）。
- **曦码·曜（Windows 端）≠ 移动端「曦码（Xime）」**，是两个不同产品，成绩不可互推。
- 整句 ±9 点、词级 ±4 点为 95% 置信区间，段内差异别过度解读。

## 自己复测

前提：Windows 10/11；自行安装 git 和 Python 3.10+ 并加入 PATH；
被测输入法已安装并在系统语言列表里启用。

```
1. scripts\setup.bat    准备环境（自动下载测试引擎、放语料、装依赖），只需运行一次
2. scripts\run.bat      双击运行（或命令行 run.bat online），给这次测试起个名字
```

- 想改测哪些输入法：改 scripts\run.bat 开头的输入法清单。
- 想测断网成绩：自己断网（拔线/关路由/飞行模式都行），再跑一遍，名字换一个
  （比如 offline）。脚本只在开始时记录一次网络状态，之后不打扰。
- 所有东西都落在仓库目录内：引擎在 engine/，结果在 results/run/<名字>/，
  汇总自动生成 results/summary_<名字>.md。仓库放哪就在哪跑。

### 添加清单之外的输入法（不用改代码）

编辑仓库根目录的 `imes.json`，加一行即可（key 自己起名，patterns 填该输入法在
Windows 语言列表里显示名称的子串，display 是报告里的名字）：

```json
"huayu_pinyin": { "patterns": ["华宇"], "display": "华宇输入法" }
```

再把 key 加进 scripts\run.bat 的清单。未安装的输入法跑前预检会自动跳过，不会报错。
老式 IME（键盘布局注册、如华宇 V6.9）同样支持。

### 常见问题与处理

- **某个输入法没装/没启用**：起跑前自动预检（同目录 preflight.txt），未启用的
  直接跳过并注明原因，不影响其他输入法。
- **日志出现 `[ABORT] ... no committed text`（连续 8 句一个字都没上屏）**：输入法
  切过去了但引擎没工作——通常是它弹了激活/登录/升级窗口、停在英文模式，或重启后
  引擎没被唤醒。脚本会立即停止这一格并写明原因。处理：手动切换到该输入法、打一个
  字确认候选窗出现（顺手关掉弹窗），再单独补测这一家。
- **重启后第一轮缺数据**：多数商业输入法重启后需要手动激活一次。建议重启后先把
  每个要测的输入法手动切一遍、各打一个字，再跑脚本；期间保持有人值守、不要远程
  断开控制台会话。
- **结果可信度自检**：run_log.txt 里每格有一行 `[RESULT] ime=... typed=... total=... exact=...`；
  typed 远小于 total 或出现 ABORT 的格子是废数据，不要采信，补测后以新文件为准
  （汇总脚本对同一输入法取历史最优）。

## 墨奇 vs 小狼毫：产品级四臂对比（2026-10-26）

黑盒真机四臂（同机同语料同读音 sidecar、逐臂重置取证）：
小狼毫默认（明月）41.67 → +白霜 55.83 → +挂 gram **65.83**；
墨奇 1.6.1 成品 **62.50**。墨奇成品胜开箱小狼毫 +20.8 点，但优势全部来自
"默认挂模型+白霜系词库"的工程化打包——小狼毫武装到同配置即追平（CI 内），
墨奇定制层在本语料无净增益。详见 `results/fwm_product_compare.md`。
- **8 格引擎矩阵终审（同日晚）**：删净一切 gram 后四格两引擎逐格同分（明月 43.33/白霜
  55.00）；挂万象 gram 后墨奇 −0.83×2（噪声内）；速度无方向、内存 +10MB——
  **"引擎更强"不成立，可测优势全部来自默认打包**。详见 `results/engine_matrix8_scorecard.md`。
- **自训模型终审（同日深夜）**：判据改为只测自训模型。zh-newmoqi.gram（12.7MB，
  11 源/知乎域×30，管线全链路入库；2026-10-28 起居 moqi-ime 仓 `tools/gram-train`）
  白盒 +3.33（55.00→58.33）、
  词级零回归、双引擎一致——**判据通过，自训路线继续**。
- **自训终局（同日深夜二）**：泄漏审计抓出 wiki-train.txt 脏源（106/120 句）并弃用；
  nm67（67MB/15源）全拼整句 59.17 新纪录、词级零回归；混拼实证 gram 全线负资产
  （裸霜 80.44 最高、万象 40.00 最低），top3/5 零增益；abbrev_sentences 已被产品
  于 10-23 以真人回放（29.7% vs 64.8%）否决——混拼手感只剩 mixed_pair 重排与
  词条级简拼两条路。
- **mixed_pair 重排终审（10-27 凌晨）**：native 栈 A/B 实证墨奇 Go 层混拼优势——
  高频搭配对 +14.4/+8.1（500/2000 对），随机词对 −12.5（双刃，调参空间在
  ratio/floor）；词条级简拼补丁对混拼证伪。墨奇差异化第一条硬证据。

## 模型评测口径（2026-10-27 起强制）

三套口径互不可比：**引擎白盒**（只调 rime.dll）／**原生栈**（rime.dll+Go 管线，
产品真实行为，无 GUI）／**黑盒**（TSF 真机）。任何"产品表现"结论必须用原生栈或
黑盒。协议与冻结工件见 `docs/protocol_native_stack.md`。

产品栈五档实测（zhihu120，每臂双跑一致）：
**万象 63.33 > essay 58.33 > 无模型 54.17 = 自训 wiki 54.17**。
自训 wiki 模型在产品栈零增益（引擎白盒里 +0.83 的结论已被推翻），
详见 `results/native_stack_2026-10-27.md`。
**五档安装建议与依据**：`docs/install_recommendation.md`（实测：标准版混拼最优、
wanxiang 长句最强但混拼 −9.6、自训 wiki 档双维度同分暂无收益）。

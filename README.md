# windows-ime-bench

给 Windows 拼音输入法打分：模拟真人打字（连续全拼 + 空格上屏），看它打出来的
字和你想打的字一不一样。整句、两个字到四个字的高频词、联网和断网四种成绩都测。

15 家输入法的最新成绩见 `final_report.md`。

## 怎么测自己的输入法

前提：Windows 10/11；**自行安装 git 和 Python 3.10+ 并加入 PATH**；
被测的输入法已安装并在系统语言列表里启用。

把本仓库克隆（或下载解压）到任意位置，两步：

```
1. scripts\setup.bat    准备环境（自动下载测试引擎、放语料、装依赖），只需运行一次
2. scripts\run.bat      双击运行（或命令行 run.bat online），给这次测试起个名字
```

想改测哪些输入法：打开 scripts\run.bat，改开头的输入法清单。

想测断网成绩：自己断网（拔线/关路由/飞行模式都行），再跑一遍第 2 步，名字换一个（比如 offline）。脚本只在开始时记录一次网络状态，之后不再打扰。

所有东西都落在仓库目录内：测试引擎在 engine/，每次测试的结果在
results/run/<名字>/，并自动生成汇总 results/summary_<名字>.md。
仓库放哪就在哪跑，不往别处写任何文件。

## 常见问题与处理

- **某个输入法没装/没启用**：起跑前会自动预检并打印清单（同目录 preflight.txt），
  未启用的输入法直接跳过并注明原因，不影响其他输入法。
- **日志出现 `[ABORT] ... no committed text`（连续 8 句一个字都没上屏）**：输入法切过去了
  但引擎没工作——十有八九是它弹了激活/登录/升级窗口、被切到了英文模式，或重启后引擎
  没被唤醒。脚本会立即停止这一格并写明原因，不会白跑完整个语料。处理：到屏幕上手动
  切换到该输入法、打一个字确认候选窗出现（顺手关掉弹窗），再单独补测这一家。
- **重启后第一轮缺数据**：多数商业输入法重启后需要手动切换激活一次。建议重启后先把
  每个要测的输入法手动切一遍、各打一个字，再跑脚本。
- **结果可信度自检**：run_log.txt 里每格都有一行 `[RESULT] ime=... typed=... total=... exact=...`；
  typed 远小于 total 或出现 ABORT 的格子是废数据，不要采信，补测后以新文件为准
  （汇总脚本对同一输入法取历史最优，补测会自动覆盖旧的废分）。

## 语料

| 文件 | 内容 | 来源 |
|---|---|---|

这些数字怎么读、误差多大——见 `methodology.md` 和 `results/final_report.md`。
青简 v0.3.1（纯本地）：整句 49.17%、词级 98.67%，在线/离线整句一致。

**曦码·曜输入法**（2026-10-24 新增第 16 家，在线全量）：整句 40.00%（48/120）、
在线词级 99.56%（448/450）；离线轮未测。**注意区分**：社区口碑较好的移动端
「曦码（Xime）」与本次评测的 Windows 端「曦码·曜输入法（XimeYao）」是两个不同
产品，本成绩不可外推到移动端。

2026-10-24 联网复测的其余各家与历史一致（微信 71.67、百度 56.67、微软 55.83、
讯飞 38.33）；各输入法安装包/安装目录/内存实测见 final_report 总表。
谷歌拼音 2.7 已停止服务、无云可用，联网/断网成绩一致（47.50 vs 42.50，在误差
范围内）；其断网列为干净复测数据（早前被打断的断网数据作废）。

# windows-ime-bench

给 Windows 拼音输入法打分：模拟真人打字（连续全拼 + 空格上屏），看它打出来的
字和你想打的字一不一样。整句、两个字到四个字的高频词、联网和断网四种成绩都测。

结论速记：

- **微信在线整句第一（70.83%，两轮逐位一致），但清缓存断网后 35.83%（−35）**：
  整句优势依赖联网数据；纯本地榜 QQ 62.50% 领跑（QQ/千问/墨奇/手心/微软/水杉
  在线离线零变化）。
- **联网依赖实锤两家：微信 −35、百度 −17.5**；搜狗新装在线离线逐位相同（双
  55%）、豆包断网不降——两家云增益均为 0，重置脚本误清搜狗共享词库时会假低
  到 35%（脚本已修）。
- **素言/清风词级满分**（整句偏弱）；谷歌已停服，默认设置词库 88.89% 是真短板
  （用户关掉默认选项后整句掉到 30.83%，配置敏感性大）。
- 华宇 V6.9（2017 停更）纯本地无云，整句 53.33% 仍在一梯队下沿，**全场最轻**
  （包 17MB/目录 14MB/零常驻）。
- **曦码·曜（Windows 端）≠ 移动端「曦码（Xime）」**，是两个不同产品，成绩不可互推。
- 整句 ±9 点、词级 ±4 点为 95% 置信区间，段内差异别过度解读。

## Rime 方案白榜（另一口径，勿与上表混比）

小狼毫体系内 5 个全拼方案走 **librime 白盒**（零用户词库/零云/逐句确定性，
两轮 0 diff），首跑 98 s 复跑 41 s；语料读音以 gold sidecar 冻结（词库交叉审计，
曾抓出 pypinyin「尼泊尔」po→bo 3 句错音）。整句 zhihu120：**白霜 55.00 > 雾凇
51.67 > 薄荷 49.17 > 万象 48.33 > 明月 43.33**；挂同一 gram 后 白霜 65.83 >
雾凇=薄荷 60.83 > 万象 60.00 > 明月 48.33——两口径排序同构。词级 words234：
雾凇/白霜 100%，其余 99.78%。详见 `results/whitebox_rime_report.md`。追加引擎 A/B：墨奇 1.6.1 产品引擎 vs 小狼毫 0.17.4 同方案白盒——词级逐位一致、整句统计打平（分歧仅现于 gram 组句），墨奇优势在产品层与方案可插拔。


## 自己复测

前提：Windows 10/11；自行安装 git 和 Python 3.10+ 并加入 PATH；
被测输入法已安装并在系统语言列表里启用。

```
1. scripts\setup.bat    准备环境（自动下载测试引擎、放语料、装依赖），只需运行一次
2. scripts\run.bat      双击运行（或命令行 run.bat online），给这次测试起个名字
```

- 想改测哪些输入法：改 scripts\run.bat 开头的输入法清单。
- 想测断网成绩：自己断网（拔线/关路由/飞行模式都行），再跑一遍，名字换一个
  （比如 offline）。脚本只在开始时记录一次网络状态，之后不打扰。
- 所有东西都落在仓库目录内：引擎在 engine/，结果在 results/run/<名字>/，
  汇总自动生成 results/summary_<名字>.md。仓库放哪就在哪跑。

### 添加清单之外的输入法（不用改代码）

编辑仓库根目录的 `imes.json`，加一行即可（key 自己起名，patterns 填该输入法在
Windows 语言列表里显示名称的子串，display 是报告里的名字）：

```json
"huayu_pinyin": { "patterns": ["华宇"], "display": "华宇输入法" }
```

再把 key 加进 scripts\run.bat 的清单。未安装的输入法跑前预检会自动跳过，不会报错。
老式 IME（键盘布局注册、如华宇 V6.9）同样支持。

### 常见问题与处理

- **某个输入法没装/没启用**：起跑前自动预检（同目录 preflight.txt），未启用的
  直接跳过并注明原因，不影响其他输入法。
- **日志出现 `[ABORT] ... no committed text`（连续 8 句一个字都没上屏）**：输入法
  切过去了但引擎没工作——通常是它弹了激活/登录/升级窗口、停在英文模式，或重启后
  引擎没被唤醒。脚本会立即停止这一格并写明原因。处理：手动切换到该输入法、打一个
  字确认候选窗出现（顺手关掉弹窗），再单独补测这一家。
- **重启后第一轮缺数据**：多数商业输入法重启后需要手动激活一次。建议重启后先把
  每个要测的输入法手动切一遍、各打一个字，再跑脚本；期间保持有人值守、不要远程
  断开控制台会话。
- **结果可信度自检**：run_log.txt 里每格有一行 `[RESULT] ime=... typed=... total=... exact=...`；
  typed 远小于 total 或出现 ABORT 的格子是废数据，不要采信，补测后以新文件为准
  （汇总脚本对同一输入法取历史最优）。

## 墨奇 vs 小狼毫：产品级四臂对比（2026-10-26）

黑盒真机四臂（同机同语料同读音 sidecar、逐臂重置取证）：
小狼毫默认（明月）41.67 → +白霜 55.83 → +挂 gram **65.83**；
墨奇 1.6.1 成品 **62.50**。墨奇成品胜开箱小狼毫 +20.8 点，但优势全部来自
"默认挂模型+白霜系词库"的工程化打包——小狼毫武装到同配置即追平（CI 内），
墨奇定制层在本语料无净增益。详见 `results/fwm_product_compare.md`。
- **8 格引擎矩阵终审（同日晚）**：删净一切 gram 后四格两引擎逐格同分（明月 43.33/白霜
  55.00）；挂万象 gram 后墨奇 −0.83×2（噪声内）；速度无方向、内存 +10MB——
  **"引擎更强"不成立，可测优势全部来自默认打包**。详见 `results/engine_matrix8_scorecard.md`。

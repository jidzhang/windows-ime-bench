# windows-ime-bench

给 Windows 拼音输入法打分：模拟真人打字（连续全拼 + 空格上屏），看它打出来的
字和你想打的字一不一样。整句、两个字到四个字的高频词、联网和断网四种成绩都测。

17 家输入法的成绩见 `final_report.md`。

## 怎么测自己的输入法

前提：Windows 10/11；**自行安装 git 和 Python 3.10+ 并加入 PATH**；
被测的输入法已安装并在系统语言列表里启用。

把本仓库克隆（或下载解压）到任意位置，两步：

```
1. scripts\setup.bat    准备环境（自动下载测试引擎、放语料、装依赖），只需运行一次
2. scripts\run.bat      双击运行（或命令行 run.bat online），给这次测试起个名字
```

- 想改测哪些输入法：改 scripts\run.bat 开头的输入法清单。
- 想测断网成绩：自己断网（拔线/关路由/飞行模式都行），再跑一遍，名字换一个
  （比如 offline）。脚本只在开始时记录一次网络状态，之后不打扰。
- 所有东西都落在仓库目录内：引擎在 engine/，结果在 results/run/<名字>/，
  汇总自动生成 results/summary_<名字>.md。仓库放哪就在哪跑。

## 添加清单之外的输入法（不用改代码）

编辑仓库根目录的 `imes.json`，加一行即可（key 自己起名，patterns 填该输入法在
Windows 语言列表里显示名称的子串，display 是报告里的名字）：

```json
"huayu_pinyin": { "patterns": ["华宇"], "display": "华宇输入法" }
```

再把 key 加进 scripts\run.bat 的清单。未安装的输入法跑前预检会自动跳过，不会报错。
老式 IME（键盘布局注册、如华宇 V6.9）同样支持。

## 常见问题与处理

- **某个输入法没装/没启用**：起跑前自动预检（同目录 preflight.txt），未启用的
  直接跳过并注明原因，不影响其他输入法。
- **日志出现 `[ABORT] ... no committed text`（连续 8 句一个字都没上屏）**：输入法
  切过去了但引擎没工作——通常是它弹了激活/登录/升级窗口、停在英文模式，或重启后
  引擎没被唤醒。脚本会立即停止这一格并写明原因。处理：手动切换到该输入法、打一个
  字确认候选窗出现（顺手关掉弹窗），再单独补测这一家。
- **重启后第一轮缺数据**：多数商业输入法重启后需要手动激活一次。建议重启后先把
  每个要测的输入法手动切一遍、各打一个字，再跑脚本；期间保持有人值守、不要远程
  断开控制台会话。
- **结果可信度自检**：run_log.txt 里每格有一行 `[RESULT] ime=... typed=... total=... exact=...`；
  typed 远小于 total 或出现 ABORT 的格子是废数据，不要采信，补测后以新文件为准
  （汇总脚本对同一输入法取历史最优）。
